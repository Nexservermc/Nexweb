常见问题

来自官方 Wiki 常见问题板块，加入服务器前你可能想了解这些

打开 Minecraft Java 版客户端，点击「多人游戏」→「添加服务器」，把服务器地址复制进去，点击完成即可。服务器几乎支持所有 Java 版本（不支持快照版和愚人节版本哦）。

当前主地址：nexserver.top

完整地址信息请加入官方 QQ 群 277897347 或 Telegram 获取。

  • 检查版本是否正确（不支持快照版和愚人节版本）
  • 服务器维护期间无法加入，可在群里跟踪维护消息
  • 检查网络是否正常，必要时重启游戏或电脑
  • 还不行就来联系管理员吧，我们会帮你解决的~
  • 离线账号请先到 NameMC 查询用户名是否与正版玩家重复，如有请联系服主
  • 检查网络能否正常上网、能否访问皮肤站或 Microsoft 账号
  • 重启启动器，或换个启动器试试
  • 如果大家都登不上，可能是服务器在维护，耐心等待~

手机也能玩哦！不过要注意我们只支持国际版 Minecraft，网易版暂时不行。

  • 只是几块方块的话，悄悄补回去就好啦，还可以放个告示牌道个歉（可选）
  • 破坏得比较多，赶紧去 QQ 群联系管理员，他们可以帮忙回滚区域
  • 如果回滚出了问题，记得好好跟对方沟通，大家都是朋友~

如果你觉得有误会或不公平，直接申诉就好。把情况说清楚，最好提供截图或录像当证据，我们会认真调查，保证给你一个公正的处理结果~

详见「服务器规定」栏目，共 17 条，涵盖建筑、行为、社区交流等各个方面。完整规则请看 官方 Wiki，看不懂的地方随时问管理员~
